## 运行产物

`<store>/tasks/<task_id>/runs/<run_id>/`：

- `run.json`：状态、planned_order、execution_order、final_step_id、workspace_init。
- `workspace/`：过滤后的当前工作树，共享给该 Run 的步骤。
- `steps/S<n>.json`：步骤结果、成本、报告及完整输出引用；尾部文本继续用于界面摘要。
- `steps/S<n>.stdout.txt`、`steps/S<n>.stderr.txt`：进入执行器阶段的每步完整文本，不会因下一步覆盖 output.md 而丢失。预算或预检失败只有结果记录。

`.icleignore` 放在项目根目录，每行一个 glob；空行和以 `#` 开头的行忽略。模式匹配相对路径或文件/目录名；只支持增加排除，不支持 `!` 反选。复制限 5,000 文件、每文件 25 MiB，排除清单记录未复制项。执行存储位于项目内部时，跳过它所在的一级目录，防止把执行状态递归复制到自身。输出页显示来源提交与排除清单。

`tests/test_reliability.py` 新增 24 个回归测试，覆盖真实模块调用、临时 Git 仓库、伪模型 API 执行器、环回 HTTP 重定向服务器、双线程及双进程配置保存。

首批测试在未修复代码上复现了地址绕过、归属篡改通过、步骤依赖错接、交接内容缺失、回读顺序错误、敏感文件复制。后续先写失败测试，再修复并发丢失、删除 ID 复用、收尾报告错误兜底和规划器身份转换。
