# Local UI fonts

Noto Sans SC and Space Grotesk are served locally as unmodified WOFF2 Unicode subsets from Google Fonts, at weights 400–600. The accompanying OFL files retain their licenses and copyright notices.

- Noto Sans SC: https://github.com/google/fonts/tree/main/ofl/notosanssc
- Space Grotesk: https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- Subset CSS source: https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400..600&family=Space+Grotesk:wght@400..600&display=swap
- Downloaded: 2026-09-07

The 27 selected Unicode subsets cover the current static UI text. Characters outside these ranges use the system fallback. Font files are loaded only as their Unicode ranges are needed; the UI does not request fonts from Google at runtime.
